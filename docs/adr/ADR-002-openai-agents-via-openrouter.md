# ADR-002. ИИ-агент на OpenAI Agents SDK через OpenRouter с собственной трассой и счётчиком шагов

**Статус:** принято, 2026-11-13

## Контекст

Раздел 7 ТЗ требует от агента формального контракта: не более пяти вызовов инструментов на один ответ, трасса каждого ответа (запрос, план, инструменты и аргументы, идентификаторы событий-оснований, задержка, токены, стоимость), доступная из админки, и резервный режим без модели. Модель подключается через OpenRouter по OpenAI-совместимому API. Основная модель `google/gemini-3.8-flash`. Порог стоимости диалога для уровня 4 составляет 3 ₽.

## Решение

Агент строится на `openai-agents` (OpenAI Agents SDK) с моделью `OpenAIChatCompletionsModel` поверх `AsyncOpenAI(base_url=LANGUAGE_MODEL_BASE_URL)`. Три встроенных механизма SDK заменены собственными.

1. **Трасса.** Экспорт трасс SDK в OpenAI отключён (`set_tracing_disabled(True)`). Без ключа OpenAI он выдаёт ошибки, а с ключом передавал бы запросы жителей ещё одной стороне. Трасса пишется в таблицу `agent_traces` в формате раздела 7.4 ТЗ.
2. **Лимит шагов.** `max_turns` в SDK считает вызовы модели, а не инструментов. Модели Gemini на OpenRouter не принимают `parallel_tool_calls`, поэтому за один ход модель может запросить несколько инструментов. Пять вызовов инструментов на ответ считает общий счётчик в контексте запуска. Каждый инструмент проверяет его перед выполнением. Шестой и последующие вызовы не выполняются, возвращают `{"error": "step_limit_reached"}` и записываются в трассу. `max_turns` остаётся страховкой от зацикливания.
3. **Стоимость.** Стоимость ответа в рублях считается по токенам, включая чтение из кеша, по тарифам модели в долларах из конфигурации и по фиксированному курсу из `.env`. Прогон оценки сверяет этот расчёт с данными OpenRouter.

Адрес, ключ, имя модели и тарифы задаются в `.env`. Смена модели не требует правки кода и нового ADR.

## Рассмотренные альтернативы

- **LangGraph.** Отклонён: архитектура проекта уже построена вокруг `openai-agents`, а собственные трасса и лимит шагов понадобились бы и с ним.
- **Собственный цикл на SDK `openai`** (около 150 строк). Даёт полный контроль, но разбор вызовов инструментов, схемы инструментов и guardrails пришлось бы писать вручную. Остаётся запасным путём: выбор изолирован портом `AgentOrchestratorPort`, и замена не затрагивает сценарии использования.

## Последствия

- В первом прототипе нужно проверить на `gemini-3.8-flash` через OpenRouter три вещи: работает ли структурированный финальный ответ (`output_type`) вместе с инструментами в одном запросе, кешируется ли неизменный префикс (системный промпт и схемы инструментов) и приходит ли `cached_tokens` в `usage`. Если структурированный ответ вместе с инструментами не работает, финальный ответ возвращается через служебный инструмент, который не входит в лимит шагов.
- Обновление `openai-agents` может изменить поведение хуков и контекста запуска. Версия фиксируется в `uv.lock`, счётчик шагов покрывается модульным тестом.
