# Афиша культуры Башкортостана

Информационный сервис о культурных мероприятиях Республики Башкортостан для жителей и гостей, со встраиванием на сайт Министерства культуры РБ. Ключевая ценность — достоверность: каждое утверждение опирается на запись каталога и её источник.

## Каталог

**Событие**:
Одно культурное мероприятие в каталоге после сведения дублей. Одному событию соответствует одна карточка, даже если оно пришло из нескольких источников.
_Avoid_: мероприятие-запись, анонс, пост

**Карточка**:
Представление события пользователю: название, категория, дата и время, город и площадка, адрес, описание, цена, возраст, ссылки и список источников.
_Avoid_: страница события, пост

**Категория**:
Тип события из закрытого перечня: концерт, спектакль, выставка, фестиваль, кино, экскурсия, другое.
_Avoid_: жанр, рубрика

**Метка**:
Свободное уточнение события, не входящее в категории: «джаз», «дети», «бесплатно», «башкирский язык».
_Avoid_: тег (в текстах для людей), ключевое слово

**Площадка**:
Конкретное место проведения события с адресом в определённом городе или населённом пункте.
_Avoid_: место, локация, зал

**Город**:
Город или населённый пункт республики из справочника, к которому приводятся все написания из источников.
_Avoid_: локация, регион

**Статус события**:
Одно из трёх состояний: «Опубликовано» (в выдаче), «Черновик» (не в выдаче, ждёт проверки), «Отменено» (не в выдаче, но открывается по прямой ссылке с явной пометкой).
_Avoid_: «удалено», «скрыто», «архив»

**Снятие события**:
Перевод события в статус «Отменено» модератором или по данным источника.
_Avoid_: удаление события

## Источники и сбор

**Источник**:
Откуда получено событие: ручной ввод, файл импорта, RSS, API или страница учреждения. У события может быть несколько источников.
_Avoid_: фид, провайдер данных

**Сырая запись**:
Данные источника в том виде, в каком они получены, до нормализации. Хранится отдельно, чтобы нормализацию можно было переиграть без повторного сбора.
_Avoid_: исходник, дамп

**Нормализация**:
Приведение сырой записи к единой схеме события: формат дат, цена из текста, город и площадка из справочника, возраст.
_Avoid_: парсинг, очистка

**Дубль**:
Две записи, описывающие одно и то же событие: совпадают нормализованное название, дата и площадка.
_Avoid_: копия, повтор

**Дедупликация**:
Сведение дублей из разных источников в одно событие с сохранением списка всех источников.
_Avoid_: слияние, мерж

**Уверенность**:
Оценка от 0 до 1 того, насколько надёжно поля события извлечены из источника.
_Avoid_: score, рейтинг

**Очередь модерации**:
Список спорных карточек, которые не попадают в выдачу, пока их не проверит модератор: неполные поля, битая ссылка, дата в прошлом, подозрение на дубль или инъекцию.
_Avoid_: модерационный буфер, карантин

**Отчёт об импорте**:
Итог загрузки файла: сколько событий добавлено, обновлено и отклонено, с причиной по каждому отклонению.
_Avoid_: лог импорта

## Пользователи и взаимодействие

**Житель**:
Пользователь, который ищет, куда пойти, с ограничениями по дате, городу, цене и возрасту.
_Avoid_: клиент, юзер

**Гость республики**:
Пользователь, который ищет события на конкретные даты рядом с местом пребывания.
_Avoid_: турист

**Организатор**:
Учреждение или человек, проводящий событие и отправляющий обращения.
_Avoid_: партнёр, площадка (площадка — это место, а не организатор)

**Модератор**:
Сотрудник, который загружает события, проверяет очередь модерации и снимает отменённые события.
_Avoid_: администратор (в значении роли), редактор

**Подписка**:
Сохранённый фильтр (город, категория, период), по которому пользователю приходят новые события. Содержит только идентификатор пользователя и фильтр; отписка удаляет её полностью.
_Avoid_: рассылка, follow

**Обращение**:
Заявка или уточнение от организатора по событию, переданное ответственному.
_Avoid_: фидбек, отзыв, тикет

**Журнал изменений**:
Запись о каждом изменении данных: кто, когда и что изменил.
_Avoid_: лог, история правок

## Агент

**Агент**:
Диалоговый помощник, который по свободному запросу строит план, вызывает инструменты и формирует ответ, используя результаты инструментов как единственный источник фактов.
_Avoid_: чат-бот, ИИ, нейросеть

**Ограничение**:
Отдельное условие из запроса пользователя: дата, время, город, цена, возраст, длительность, время на перемещение. Каждое ограничение проверяется по данным.
_Avoid_: фильтр (фильтр — элемент интерфейса), параметр

**Уточняющий вопрос**:
Единственный вопрос агента при неоднозначном запросе, когда полезный ответ без него невозможен.
_Avoid_: допрос, серия вопросов

**Обоснованный отказ**:
Прямой ответ «нет данных» с указанием, какое ограничение мешает и как его можно ослабить.
_Avoid_: пустой ответ, ошибка

**Инструмент**:
Функция с формальным контрактом (аргументы и структурированный результат), доступная агенту.
_Avoid_: функция агента, плагин, скилл

**Изменяющее действие**:
Действие, меняющее данные (подписка, обращение). Выполняется только после явного подтверждения пользователем, а не по тексту запроса.
_Avoid_: мутация, команда

**Трасса**:
Запись одного ответа агента: исходный запрос, план, вызванные инструменты и аргументы, идентификаторы событий-оснований, задержка, токены и стоимость.
_Avoid_: лог агента, история вызовов

**Резервный режим**:
Работа бота и сайта обычным поиском с теми же фильтрами, когда модель недоступна или исчерпан бюджет. Включается автоматически, пользователь видит пояснение.
_Avoid_: офлайн-режим, деградация

**Инъекция**:
Инструкция, спрятанная в описании события или в сообщении пользователя, чтобы заставить агента нарушить правила. Никогда не выполняется.
_Avoid_: взлом, джейлбрейк

## Планирование и качество

**План выходного дня**:
Упорядоченные по времени 2–4 события без пересечений, с оценкой перемещений и общей стоимостью, подобранные под бюджет, окно времени, состав, город и допустимое время в пути.
_Avoid_: маршрут, расписание

**Контрольный запрос**:
Запрос из набора для оценки качества с ожидаемым поведением (найти, уточнить, отказать, не выполнить инъекцию).
_Avoid_: тест-кейс, golden query (в текстах для людей)

**Базовая линия**:
Обычный поиск по ключевым словам, с которым сравниваются метрики агента.
_Avoid_: baseline (в текстах для людей), бенчмарк
